Requests + Delivery Services

You can place a request for books and other physical materials by using the Place Hold function in library search. You can also request digital copies of print materials by using the Request Digital Copy function.

If you would like the Library to purchase a print copy of an ebook, or an e-copy of a print book, fill out the recommend a purchase form and add the following statement in the “Anything Else” box: I am aware that the Library owns a copy of this title, but I require a different format due to accessibility reasons.

Distance Delivery

Current University of Alberta students and faculty may register for delivery of library materials to a home/work address. Learn more about distance delivery

Please chat with us or email us if you have specific accommodation or delivery requests.
